# Orbbt Landing Page

Static landing page for Orbbt, a job hunt companion.

## Pages

- `index.html` - Home, features, pricing, contact, FAQ, footer
- `auth.html` - Sign up / log in demo page
- `waitlist.html` - Waitlist demo page
- `privacy-policy.html` - Privacy policy
- `terms-and-conditions.html` - Terms and conditions
- `refund-policy.html` - Refund policy

## Deploy

This is a static site. You can deploy the folder with GitHub Pages, Netlify, Vercel, or any static hosting provider.
